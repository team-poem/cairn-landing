# Hallmark 적용 검토

- 출처: Nutlope/hallmark `13ac0ec7e148655948100b6396439e481361d690`, skill 1.1.0. 디자인 기준으로 읽었으며 글로벌 스킬 설치는 하지 않았다.
- 구조: Narrative Workflow. N9 상단 링크와 Ft1 워드마크 푸터. 기존 단일 경로와 Hero/Workflow/Features/GetStarted의 컴포넌트 구분을 유지했다.
- 사용자 지시 우선: 밤하늘, 돌무더기, Galaxy, Aero Shards 유지. 재사용한 vendor·원본 SVG의 셰이더·색상은 신규 UI 토큰 규칙의 적용 대상에서 제외했다. GPU용 HEX 토큰은 기존 색과 일치하는 참고값이다.
- 전역 CSS를 덮어쓰지 않고 app/hallmark.css와 tokens.css를 연결했다. 프레임워크 CSS 지시문과 의존성을 유지했다.
- 문구: 과장된 영구 재생 주장, 반복적인 수식어, 장식용 대문자 섹션 라벨을 제거했다. 화면과 접근성 라벨 및 메타데이터는 영어다. 모델 호출 없음은 기본 재생의 범위다.
- 내용의 근거: 실제 제품 문서의 discover/freeze/replay/heal, JSON, TraceSink와 포트, CLI 안내만 사용했다. 통계·고객·사용 후기는 추가하지 않았다. 설명용 데모임을 표시했다.

## 소스 기반 점검

- 자기 검토: Philosophy 4, Hierarchy 4, Execution 3, Specificity 5, Restraint 4, Variety 4. Execution은 렌더링을 직접 확인하지 않았으므로 보수적으로 평가했다.
- 레이아웃: 이미지 포함 grid는 minmax(0,1fr), 루트 overflow-x:clip, 헤더 긴 단어 줄바꿈, 작은 화면 기본 단일 열, 40rem/60rem 분기. 320/375/414/768px의 실제 렌더링 검증은 수행하지 않았다.
- 상태: Base UI 탭과 버튼, 즉시 표시되는 focus-visible, 활성·비활성·실행 중·완료·복구 필요 상태. 설명용 단계 전환과 정지 가능한 배경 모션을 유지했다.
- 대비: OKLCH를 선형 sRGB로 변환해 정적 토큰 쌍을 계산했다. 일반 텍스트 대비 최소 6.09:1, 주 CTA 9.74:1. GPU 배경 위 실제 합성 대비는 브라우저 검사 대상이다.
- UI 패턴: 같은 크기의 3열 카드, 카드 중첩, 가짜 브라우저 창, 그라디언트 제목, 이탤릭 제목, scroll reveal 없음.
- 58개 기준을 읽고 소스에 적용 가능한 항목을 검토했다. 브라우저 관찰이 필요한 34/44/49 및 시각 배치 검사는 미검증이며 58/58 통과를 주장하지 않는다. 짧은 인터페이스 설명의 줄 길이와 사용자가 유지한 장식 효과는 제품 맥락에 맞췄다.
